Rules

Synthorium Discord server guidelines.

Respect & Support

Be respectful to all members. No insults, discrimination, harassment, or toxic behavior will be tolerated.

AI Usage

AI is an assistant, not a 100% developer. Do not post fully AI-generated code without testing, understanding, and validating it yourself. Human work remains core.

Archipelago Disclaimer

No confusion with the official project. Our multiworld projects are independent. Do not share misleading links or ping the official Archipelago team for our custom mods.

Content & Security

No spam, malicious links, or piracy. Only share safe code and use the appropriate thematic channels for your discussions and projects.

Support Tickets

Use tickets wisely. Open a ticket only for actual technical issues or appeals. Please be patient with the administration team.

Disclaimer: This project uses an archipelago theme but is fully independent and not affiliated with the official Archipelago Multiworld Randomizer team.
